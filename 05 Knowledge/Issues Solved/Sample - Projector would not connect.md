# Sample - Projector would not connect

## Symptom (exact error / what I saw)
Laptop showed "No signal" on the projector during the venue visit.

## Setup (device, version, command)
Laptop with one display port, venue projector, their cable.

## What I tried (in order)
1. Unplugged and replugged the cable → no change
2. Pressed the display-switch key → no change
3. Changed the projector's input source with its remote → picture appeared

## Root cause
The projector was set to a different input.

## Fix
Use the remote: Source → pick the port the cable is in.

## How to spot it faster next time
"No signal" with a good cable usually means the wrong input. Check the source first.

## Who helped / references
Venue staff showed where the remote is kept.
