# Career Skills

Skills that make you more valuable in any role, and where to practise each in your daily work.

| Skill | Practise it by... | Evidence |
|---|---|---|
| Delivering on promises | Hitting every status update and deadline |  |
| Estimating | Comparing `est_mins` with `actual_mins` on finished tasks |  |
| Clear writing | Status updates, issue notes |  |
| Understanding who uses your work | Asking who relies on what you deliver, and why |  |
| Managing time | Weekly time totals by project and activity |  |
| Helping others grow | Teaching one thing you learned |  |
| Proposing improvements | Suggesting one change, with numbers |  |
