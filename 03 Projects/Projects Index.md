# Projects Index

Each project is a folder. Make a new one with **Menu → N**; it creates all five parts for you. Table view: [[Projects.base|Projects]].

| Part | What goes in it |
|---|---|
| `Project name` (home note) | Goal, done means, milestones, task list, decisions |
| `... - Info & Messages` | Chats, emails and facts from other people (Menu → V pastes the clipboard here) |
| `... - Learning Notes` | What you worked out yourself |
| `... - Explain It` | How you would explain the project at the end |
| `Tasks` folder | One note per task, each with its procedure and its own time log |
