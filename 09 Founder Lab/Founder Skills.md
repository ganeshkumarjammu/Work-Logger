# Founder Skills

What running a company needs, and where you can practise each inside your current job.

| Skill | Practise it at work by... | Evidence |
|---|---|---|
| Delivering on promises | Hitting every status update and deadline |  |
| Estimating | Comparing `est_mins` with `actual_mins` on finished tasks |  |
| Clear writing | Status updates, issue notes |  |
| Understanding customers | Asking who uses what you test, and why |  |
| Managing money/time | Weekly time totals by project |  |
| Leading people | Teaching one thing you learned |  |
| Selling an idea | Proposing one improvement with numbers |  |
