# Situations

What to do when real life happens. "Menu" means: Ctrl+Shift+M on the laptop, the grid icon on the phone. Then press or tap the letter.

## Things land on me
| Situation | Do this |
|---|---|
| Someone asks me for something while I am busy | **Menu → I**, type one line, Enter. Keep working |
| I remember something unrelated | **Menu → I** |
| Someone sends a message about a project | Copy it → **Menu → V** |
| A message arrives and I do not know which project it belongs to | Copy it → **Menu → V** → choose "Inbox (decide later)" |
| The Inbox is filling up | **Menu → P** once a day (it is on the Shutdown list). Each item becomes: do now / task for later / small to-do / project info / delete |
| I am on my phone | Tap the grid icon → Capture to Inbox |

## Starting and switching work
| Situation | Do this |
|---|---|
| New piece of work | **Menu → T**, type the name |
| Going back to a task from earlier or yesterday | **Menu → R**, pick it |
| Urgent thing interrupts my task | **Menu → T** for the urgent thing. The old task is stopped and logged by itself. Afterwards **Menu → R** to go back |
| A 2-minute job not worth a note | Just do it. If you want it counted: **Menu → O** (today's note) then **Menu → S**; it is logged as "General work" |
| Work with no note: lab, helping a colleague | **Menu → O** then **Menu → S**. Or do it and press **Menu → L** afterwards |
| A task turns out to be big | **Menu → N** (new project), then make its tasks inside it |
| Same task name in two projects | Handled: the second one gets the project name added |

## Timer mistakes
| Situation | Do this |
|---|---|
| Forgot to start the timer | Open the task → **Menu → L** → pick how long |
| Forgot to stop (lunch, went home) | Press **Menu → S**. If it ran over 3 hours you are asked how much to log |
| Stopped on the wrong note, or logged by mistake | **Menu → Z** (on the device that made the log) |
| Break or lunch | **Menu → S** to stop; **Menu → R** when back |
| Closed Obsidian with the timer running | It keeps counting. On reopening you are told it is still running |
| Started the timer on the laptop, now I am on the phone | Open the menu on the phone: it shows the same running timer. **S** stops it |
| A log line is wrong and it is not the last one | Edit or delete the line by hand in today's note. The scoreboard recalculates from the notes |

## Meetings
| Situation | Do this |
|---|---|
| A regular meeting starts | **Menu → M**, pick it. Last time's open actions are already listed |
| A one-off meeting | **Menu → M** → "Other" → type a name |
| I got an action in the meeting | Type it under Actions starting with "Me:". It carries over until ticked |
| I need to say what I did this week | **Menu → W** before the meeting |

## Reporting
| Situation | Do this |
|---|---|
| End of day status | **Menu → U**, paste. Add Blocked / Next in today's note first if you have any |
| Manager asks "what are you working on?" | **Menu → U** |
| Year-end review | [[Proof of Work]] plus the weekly reports in `04 Reviews/Weekly` |
| Asked to explain a task | Open the task → "7 Explain it" |
| Asked to explain a project | Open its **Explain It** note |

## When things go wrong
| Situation | Do this |
|---|---|
| I am stuck for 30 minutes | Read your "4 Do" notes, then ask someone and show what you tried |
| I missed a whole day of logging | Start the timer once today. Do not try to rebuild yesterday |
| Ctrl+Shift+M does nothing or does something else | **Menu → K** from the grid icon shows what clashes. Change the key in Settings → Hotkeys → search "Work OS" |
| The phone shows different numbers from the laptop | Sync has not finished. Wait for the sync icon, then reopen [[Home]]. See [[Sync Setup]] |
| I want a list of all my open tasks | [[Task Board.base\|Task Board]], or the table on [[Home]] |
| The grid icon is missing | Settings → Community plugins → switch on Work OS Logger. If the company blocks community plugins, the menu and timer cannot run on that computer |
| I finished a task by mistake | Open it, change `status: done` to `status: doing` at the top, and untick it in the project note |
