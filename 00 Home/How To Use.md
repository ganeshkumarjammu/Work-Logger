# How To Use

**Menu** means: press **Ctrl+Shift+M** on the laptop, or tap the **grid icon** on the phone. Then press or tap one letter.

Want to see it filled in first? Open the sample tour from [[Home]] (it is removed with the samples).

## Task or project?
| | Task | Project |
|---|---|---|
| What it is | One piece of work with one result | A goal that needs several tasks |
| How long | Hours, or a few sittings | Days or weeks |
| Example | "Book the venue" | "Team offsite" |
| In the vault | One note, with its own timer and Time Log | A folder: home note, Info & Messages, Learning Notes, Explain It, and its tasks |
| Make it with | Menu → **T** | Menu → **N** |

Even smaller things ("call the caterer") are just a checkbox `- [ ]` in any note. They still show up in [[All Tasks]].

## The letters you need
| Key | When |
|---|---|
| **T** | You start new work. Type its name; pick the project |
| **R** | You go back to a task you started before |
| **E** | You move on to the next step |
| **I** | Something interrupts you |
| **S** | You stop or take a break |
| **V** | You copied something worth keeping (message, email, AI answer) |
| **D** | The task is finished |
| **U** | End of day: copy your status |
| **A** | See every task and checkbox in one list |

## Every time the timer starts, it asks what you are doing
A box appears with buttons. **Tap one; you do not have to type.**

🔨 Doing the work · 📚 Learning / research · 💬 Messages and calls · 📅 Meeting · 🧭 Planning · 📋 Updates and admin

If you like, type a few words first ("read the error logs"). Enter picks 🔨. Esc keeps 🔨. The clock already started when you pressed the key, so the box costs no time.

Each button has its sign. The sign is written on every log line, and the scoreboard shows **This week by activity**, so you see where your time really goes.

## Start and end times are never typed
- **Start:** when you press T, R or S, or the moment you pressed E for the step before.
- **End:** when you press E, S or I.
- **Minutes:** worked out for you and written as `[mins:: 20]`. Under 15 seconds is not logged; anything longer counts as at least 1 minute.
- **Forgot to start?** Open the task → Menu → **L** → tap how long.
- **Wrong?** Menu → **Z** removes the last log. Older lines you can edit by hand; the totals follow the lines.
- After every log, a message in the top-right corner says where it was written. **Click it** to jump there.

## One task, start to finish (example)
| Clock | You press | What happens |
|---|---|---|
| 14:00 | Menu → **T**, type `Prepare the agenda`, pick the project. Tap 📚, type `read last 3 agendas` | Task note opens. Timer runs. Status becomes `doing` |
| 14:20 | Menu → **E**. Tap 🔨, type `draft the agenda` | First step logged. Next step timed from 14:20 |
| 14:25 | Copy an AI answer → Menu → **V** → *AI answer* | Added to the task under **2 Gather** |
| 14:30 | A colleague calls: Menu → **I** → *Deal with it now*, type `phone call` | The task step is logged and paused. The call is timed as ⚡ |
| 14:40 | Menu → **S** → *Back to: Prepare the agenda* | Call logged. The task timer restarts with the same activity |
| 15:10 | Menu → **S** | Last step logged. Timer off |
| later | Fill **7 Explain it**. Menu → **D** | Task finished, ticked in the project |

**Bottom of the task note:**
```
## Time Log
- 2026-11-18 14:00-14:20 [mins:: 20] 📚 read last 3 agendas
- 2026-11-18 14:20-14:30 [mins:: 10] 🔨 draft the agenda
- 2026-11-18 14:40-15:10 [mins:: 30] 🔨 draft the agenda
```
**Today's note:**
```
- 14:00-14:20 [mins:: 20] 📚 [[Prepare the agenda]] · [[Office Move]] — read last 3 agendas
- 14:20-14:30 [mins:: 10] 🔨 [[Prepare the agenda]] · [[Office Move]] — draft the agenda
- 14:30-14:40 [mins:: 10] ⚡ Interruption — phone call
- 14:40-15:10 [mins:: 30] 🔨 [[Prepare the agenda]] · [[Office Move]] — draft the agenda
```
Each line: start-end · minutes · activity sign · what it was.

## When something interrupts you
Menu → **I**, then pick:
- **Note it for later**: type one line; it goes to the [[Inbox]]. Your timer keeps going.
- **Deal with it now**: your task step is logged and paused. The interruption is timed as ⚡ (type what it is, or press Esc). When it is over, Menu → **S** and tap **Back to: your task**. Menu → **B** does the same.

Interruptions are counted separately, so the scoreboard shows how much time they cost.

## Where each thing goes
| You have... | Put it in... | How |
|---|---|---|
| Anything gathered for one task: messages, emails, notes, links | That task → **2 Gather** | Type or paste there, or copy → Menu → **V** with the task open |
| An answer from ChatGPT, Claude or another AI | Same place, marked *AI answer* | Copy → Menu → **V** → AI answer. Check it before relying on it |
| Information about the whole project | The project's **Info & Messages** | Open it (or the project's home note) → Menu → **V**, or paste under Log |
| What was asked of you | Task → **1 Understand** | Type it in their words |
| What you tried and what happened | Task → **4 Do** | One line per try |
| What you understood | Task → **7 Explain it** | 5 short lines at the end |
| A lesson for other work too | Project's **Learning Notes** | Fill an idea block |
| Something unrelated | **Inbox** | Menu → **I** → note it for later |

## Daily, weekly, monthly, quarterly and yearly notes
The vault comes with the **Periodic Notes** add-on switched on. All of these notes live together in one folder, `01 Journal`, with no subfolders. Their names keep them apart and in date order:

| Note | Name | Opens with |
|---|---|---|
| Day | `2026-11-19` | Menu → **O**, or Ctrl+P → "Open today's daily note" |
| Week | `2026-W47` | Menu → **W** (fills in the week's numbers), or Ctrl+P → "Open this week's note" |
| Month | `2026-11` | Ctrl+P → "Open this month's note" |
| Quarter | `2026-Q4` | Ctrl+P → "Open this quarter's note" |
| Year | `2026` | Ctrl+P → "Open this years's note" (spelled that way by the add-on) |

Each new one starts from its template in `90 Templates`. Ctrl+P also has "Open next weekly note", "Open previous daily note" and so on for each kind. Do not change the folder or name formats in Periodic Notes' settings: the timer looks for daily notes in `01 Journal` with names like `2026-11-19`.

Have journal notes from an earlier version (in `01 Daily`, in `2026/11` subfolders, or in `04 Reviews/Weekly` and `Monthly`)? A message appears at start-up: click it, or Ctrl+P → "Work OS Logger: Move journal notes into 01 Journal". Links keep working.

## Every new file is recorded
When any new file appears in the vault, the add-on adds a line to [[File History]] (time, link, folder, type), and gives new notes a `created` date and a `type` at the top. [[Files.base|Files]] is a table of every note with those properties; click a column to sort.

## All tasks in one place
Menu → **A** (or [[Home]]): every open task note by project, and every unticked checkbox in every note. Tick there to tick it in its own note. Click the text to jump to it.

## Status
- **Task:** `todo` → `doing` (timer starts) → `done` (D). Waiting on someone: change it to `waiting` at the top of the note.
- **Your day:** Menu → **U** copies it from today's Time Log.

## Connecting similar notes
- Type `[[` and pick a note to link it.
- Use the same topic link in every note about one subject, for example `[[Planning]]`. Open that topic: the bottom lists every note that mentions it.
- Learning Notes have a **Related** line for this.

## Nothing shows up?
If Home shows a grey box saying "the Work OS add-on is not running", turn it on: Settings → Community plugins → Work OS Logger. After copying in a new version, switch it off and on again, or restart Obsidian. The menu shows the add-on version at the bottom; it should say 3.7.0.
