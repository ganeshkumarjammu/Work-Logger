# File History

Every new file in the vault is added here by the Work OS add-on, newest on top: when it was made, a link to it, its folder and its type. New notes also get a `created` date and a `type` at the top, so they show up in [[Files.base|Files]] (a table of every note you can sort and filter).

You do not write in this note. Renamed files keep working links; deleted files stay listed as history.
