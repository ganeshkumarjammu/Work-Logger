## 5. Now try it (5 minutes)
"Menu" = Ctrl+Shift+M on the laptop, or the grid icon on the phone.
- [ ] Menu → **R** → pick *Sample - Prepare the agenda*. A box asks **what you are doing**: tap 🔨 *Doing the work* (you may type "draft the afternoon", or not).
- [ ] Wait one minute. Menu → **E** (next step). The step is logged; the box asks again: tap 📚 *Learning / research*.
- [ ] Wait one minute. Menu → **I** → *Deal with it now*. Type "phone call" or press Esc. The task is paused; the interruption is timed.
- [ ] Menu → **S**. Choose **Back to: Sample - Prepare the agenda**. The task timer restarts.
- [ ] Menu → **S** again to stop. Click the message in the top-right corner: it opens the exact lines that were written.
- [ ] Menu → **A**: all tasks and checkboxes. Tick *Order two extra chairs* there.
- [ ] Menu → **H**: the scoreboard now shows your minutes, split by activity.
- [ ] Menu → **X** when done.
