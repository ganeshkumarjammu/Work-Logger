# Habit Engine

Why this vault is built the way it is. Charlie Munger listed the mental tendencies that drive human behaviour. A habit sticks when several of them push in the same direction (he called that a "lollapalooza effect"). Each one below is built into a button or a note.

| Munger's tendency | In plain words | Where it is built in |
|---|---|---|
| Reward super-response | We repeat what is rewarded quickly | Every stop shows minutes logged, today's total and the streak. The scoreboard updates at once |
| Doubt-avoidance | When a step needs a decision, we put it off | One menu, one letter per action. No formats to remember |
| Consistency and commitment | Once we commit, we want to stay consistent | Menu → T names the task and starts the clock: a small commitment you then want to honour |
| Deprival super-reaction | Losing something hurts more than gaining it | The streak. Weekends do not break it, so it stays fair |
| Contrast | We judge by comparison | Today vs yesterday, this week vs last week (▲ ▼) |
| Social proof and being seen | We do what others can see | Menu → U produces the status update you send every day |
| Reason-respecting | We follow through when we know why | Every project starts with "Why this exists" |
| Inversion ("invert, always invert") | Ask what would make it fail, then avoid that | "What would make it fail → avoid" in Learning Notes; [[Focus Rules]] |
| Checklists | Routine steps should not depend on memory | The 7 steps in every task note; the Shutdown list in the daily note |

## The loop
1. **Cue:** you sit down to work → Ctrl+Shift+M, then T or S.
2. **Action:** work on that one note.
3. **Reward:** stop → numbers go up, bar fills, streak grows.
4. **Proof:** Menu → U at the end of the day, Menu → W at the end of the week.

## Keep it honest
- Log real work only. Padding the numbers removes the reward, because you know.
- Minutes are the input. Finished tasks and results in [[Proof of Work]] are what count.
- Missed a day? Start the timer once today. Never miss twice.
