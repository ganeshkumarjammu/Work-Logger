# All Tasks

Every open task in the vault, in one list:
- **Task notes**: tasks made with Menu → T, grouped by project. Ticking one marks the task finished (same as Menu → D).
- **Checkboxes in your notes**: every unticked `- [ ]` line in any note (today's Top 3, meeting actions, project checklists, the Tasks list). Ticking one ticks it in its own note.

Click a line's text to jump to the note it lives in. Routine checklists (daily shutdown, the steps inside each task note, learning practice) are hidden; the button at the bottom shows them too.
